# Nuclear Reactor Palette

The dotfiles share a small radioactive-green palette so every component feels like the same desktop rather than unrelated themes.

| Token | Hex | Use |
|---|---|---|
| reactor | `#39FF14` | primary accent |
| reactor-soft | `#9DFF7A` | secondary text |
| text | `#B6FF9C` | normal foreground |
| panel | `#071407` | panel/background |
| panel-dark | `#030A03` | main background |
| border | `#176D28` | inactive borders |
| warning | `#FFF27A` | thermal warning |
| critical | `#FF3030` | thermal critical |

The intent is a **nuclear reactor control room** look: near-black surfaces, radioactive green telemetry, and yellow/red escalation states.
